# ARK-Library-Management-System
A C# Windows Forms library management system with MySQL integration for students and librarians.

## Overview
ARK helps students browse books and librarians manage borrowing/return transactions with secure login.

## Features
- Student login with ID/password
- Password reset/change
- Librarian admin dashboard
- Book borrowing and return management
- MySQL database integration

## Installation
1. Clone the repo: `git clone https://github.com/YourUsername/ARK.git`
2. Open in Visual Studio.
3. Import `ark_db.sql` into MySQL.
4. Update `app.config` with your DB credentials.

## Usage
- Students: login with ID/password.
- Librarians: login with admin credentials to access management menu.
